# Attendance

A responsive dashboard prototype for remote workforce attendance, with biometric-device status and employee journey records.

## Run locally

Open `index.html` in a modern web browser. No installation or build step is required.

## Prototype scope

The dashboard uses sample data to demonstrate attendance summaries, status filters, employee/device search, and CSV export. It does not connect to biometric hardware or verify identities. A production deployment needs a trusted server-side integration with the company's biometric devices and an authenticated attendance data source; browser-only records are not suitable as authoritative attendance data.
